# Epileptic_Disorder_Detection-_Using_EEG_Signal
This is my UG 3rd Year 1st semester project on the course "Biomedical Signal Processing", Epileptic Disorder Detection  Using EEG Signal. Here I have shown the difference between normal and epileptic EEG based on the RMS value. For those I have only used Beta and Gamma sub-band of EEG and I analyzed over inctal and interictal stages.
